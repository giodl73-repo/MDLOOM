# US-92 — Mini-bar element with explicit max

A tiny horizontal bar showing one value relative to a fixed maximum. Useful
inside dashboards or row layouts when you want a visual quantity but not a
full chart.

```proof:element kind=mini-bar value="72" max=100 width=20 no-chrome
```

```proof:element kind=mini-bar value="15" max=100 width=20 no-chrome
```

Two bars share the same max so their lengths read as proportional.
