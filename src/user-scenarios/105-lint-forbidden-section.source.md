# US-105 — Forbidden section detection (Draft / TODO / WIP)

A real published doc shouldn't have `## Draft` or `## TODO` left in. The
`md_forbidden_section` rule (configurable in proof.toml) flags these so
the author can either drop them or rename before publish.
