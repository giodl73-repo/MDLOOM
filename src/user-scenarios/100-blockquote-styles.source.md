# US-100 — Blockquote in both styles

Indent style (default markdown blockquote with `>` prefix):

```proof:blockquote attribution="Ada Lovelace"
The Analytical Engine has no pretensions whatever to originate anything.
It can do whatever we know how to order it to perform.
```

Boxed style — same content, ASCII-framed:

```proof:blockquote style=boxed attribution="Ada Lovelace"
The Analytical Engine has no pretensions whatever to originate anything.
It can do whatever we know how to order it to perform.
```
