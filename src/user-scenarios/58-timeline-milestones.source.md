# US-58 — Timeline: project milestones

Point events on a horizontal axis. Labels are auto-staggered to avoid
overlap; markers are `◆`.

```proof:chart kind=timeline width=70 title="2026 release milestones" x-label="quarter"
Kickoff: 0
v0.1 alpha: 1
v0.2 beta: 2
v0.3 release: 3
v1.0 candidate: 5
GA: 6
v1.1 patch: 8
```

Useful for status updates and roadmap views where dates matter more than
durations — for ranges, use `kind=gantt` instead.
